# Праздничный сайт

## Как получить ссылку и QR-код

1. Создай репозиторий на GitHub, например `birthday-hint`.
2. Загрузи туда файл `index.html`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. GitHub выдаст адрес вида:
   `https://ТВОЙ-ЛОГИН.github.io/birthday-hint/`
6. Этот адрес нужно использовать для QR-кода.

Страница адаптирована под смартфоны.
